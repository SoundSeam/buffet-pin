## Maintenance rule

When implementation changes a row:

1. Update current state here and the milestone in `IMPLEMENTATION_STATUS.md`.
2. Add or update automated evidence for every listed acceptance ID.
3. Update applicable manual test/runbook procedure and external gap.
4. Reassess linked risks in `RISK_REGISTER.md`.
5. Do not remove a requirement to make a milestone appear complete; record a dated decision in `DECISIONS.md` if scope changes.
